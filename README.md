# Конфигурация сервера для фитнес-клуба

Курсовая работа по автоматизации установки и настройки сервера.

## Процессы
1. Управление клиентской базой и расписанием
2. Автоматические уведомления клиентам
3. Сбор и анализ отзывов

## ПО
- ОС: Fedora Linux
- БД: PostgreSQL 15
- CRM/ERP: ERPNext
- Автоматизация: Ansible
- Бэкап: Python + cron

## Структура проекта
- `ansible/` — плейбуки и роли Ansible
- `backup_scripts/` — скрипты резервного копирования
- `docs/` — документация и диаграммы
